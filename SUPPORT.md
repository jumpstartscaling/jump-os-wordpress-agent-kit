# Support and compatibility reports

Use the [public roadmap](https://github.com/users/jumpstartscaling/projects/29) for active work and the [compatibility discussion](https://github.com/jumpstartscaling/jump-os-wordpress-agent-kit/discussions/4) for bugs, feature proposals, and provider/agent compatibility reports. Include public software versions and configuration class, never tenant credentials or customer data.

For a provider report, say whether you tested native WordPress REST, the WordPress Bridge, or the Host Gateway; include the hosting plan class, WordPress/PHP version, single-site or multisite, plugin-install permission, backup/staging availability, and the exact anonymized result.

Use [SECURITY.md](SECURITY.md) instead of an issue for a security concern.
