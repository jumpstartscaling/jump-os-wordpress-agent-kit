# Changelog

All notable changes are recorded here. This project uses Semantic Versioning; see [VERSIONING.md](VERSIONING.md).

## 0.3.3 - 2026-10-22

- Add a page-builder, plugin, and theme operating guide for humans and tenant-scoped agents.
- Cover major builder boundaries, common plugin families, official documentation discovery, ThemeForest/Envato assets, and approval/recovery gates.
- Include the guide in both the secret-free agent workspace release asset and generated private recipient packages.

## 0.3.2 - 2026-10-22

- Add a durable, repository-native public roadmap after GitHub Projects API item creation returned orphaned, non-public cards.
- Keep the public repository surface clean: one `main` branch, no open pull requests, no visible issue-form intake, a compatibility Discussion, and source-controlled roadmap status.

## 0.3.1 - 2026-10-22

- Move public work tracking to the dedicated public roadmap Project.
- Replace repository issue-form intake and automated dependency PRs with a single compatibility discussion and maintainer-reviewed updates.
- Keep the repository surface focused on source, documentation, releases, CI, and security reporting.

## 0.3.0 - 2026-10-22

- Add formal compatibility, upgrade, security, support, and governance documentation.
- Add agent-runtime deployment guidance and compatibility-report intake.
- Add legacy Host Gateway policy and client-route compatibility.

## 0.2.0 - 2026-10-22

- Introduced the provider-neutral WordPress Agent Kit, WordPress Bridge plugin, generic capability client, and initial provider guidance.

## 0.1.0 - 2026-10-22

- Introduced the original Host Gateway reference implementation.
