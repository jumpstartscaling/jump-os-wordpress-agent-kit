# Governance

The repository owner, Christopher Amaya, is the initial maintainer and release authority.

Maintainers review changes against security boundaries, compatibility policy, test evidence, documentation quality, and public-release readiness. Contributors may propose adapters and compatibility claims, but a provider is not marked verified merely because it is named in a request or issue.

Material changes—new network capability, new provider credential type, widened WordPress role, changed token scope, or public contract removal—require a documented threat-model and upgrade/rollback note before release.
